# CM3D – Master-Funktionsliste V0.1

**Stand:** 27.08.2026  
**Status:** FROZEN CANDIDATE  
**Basis:** Hauptfenster V0.1 + Funktionsmatrix V0.1 + Icon-Paket V3  
**Regel:** Diese Liste ist die projektseitig harmonisierte Funktionsbasis. Die Quellabschriften bleiben unverändert als historische Ausgangsstände erhalten.

## Release-Stufen

- **P0.1** – Minimal-Prototyp: leeres Projekt, 3D-Viewport, Objektbaum, Würfel, Auswahl, Transform, Speichern/Laden, Icons.
- **V1** – Pflichtkern des ersten belastbaren Designers.
- **V1–V2** – strukturell vorgesehen, Umsetzung nach dem Pflichtkern.
- **Später** – Ausbau/Spezialfunktionen.

Für **P0.1** wird aus der Masterliste zunächst nur folgende vertikale Kette umgesetzt:

- CM3D-F001 Neues Projekt
- CM3D-F004 Speichern
- CM3D-F008 Objektbaum
- CM3D-F009 Objekt auswählen
- CM3D-F016 3D-Hauptansicht
- CM3D-F026–F028 Grundtransform
- CM3D-F045 Quader/Würfel
- CM3D-F087 Hauptlayout
- CM3D-F088 Icon-Paket V3
- Laden eines gespeicherten Projekts als Gegenpfad zu Speichern

P0.1 ist ausdrücklich **nicht** gleich V1. V1 bleibt der größere Pflichtkern.

## Alignment-Entscheidungen

- **AL-01:** OBJ/STL-Export wird aufgenommen, Release **V1–V2**. GLB/GLTF und JSON bleiben V1.
- **AL-02:** `Projekt schließen` = **V1**; `Letzte Projekte` = **V1–V2**.
- **AL-03:** Ebenen/Layers werden als echte Funktion aufgenommen, **V1–V2**.
- **AL-04:** Base Color/Farbe = **V1**; Metallisch, Rauigkeit, Transparenz und Materialtypen = **V1–V2**.
- **AL-05:** Inspector-Pflichtkern V1 umfasst Eigenschaften, Konsole/Diagnose, Status/Warnungen/Fehler, Scene JSON und Selection; Events und Performance = **V1–V2**.
- **AL-06:** **P0.1 Minimal-Prototyp** und **V1 Pflichtkern** sind zwei ausdrücklich getrennte Ausbaustufen.

## Änderungsregel

Nach Freeze werden Funktionen nicht stillschweigend umnummeriert, gelöscht oder in andere Releases verschoben. Änderungen erfolgen über dokumentierte CM3D-Entscheidungen und eine neue Revision dieser Masterliste.
