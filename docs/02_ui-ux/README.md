# UI / UX

Dieser Bereich enthält die verbindliche Dokumentation für Hauptfenster, Bedienkonzept, Panels, Werkzeuge, Dialoge und sonstige UI-/UX-Strukturen des CyberMotion 3D Web Designers.

## Ausgangsquelle

`cybermotion_web_designer_hauptfenster_v01.docx`

## Dokumentstände

- `hauptfenster_v0.1.md` – historischer Ausgangsstand aus der ursprünglichen Hauptfenster-Dokumentation.
- `hauptfenster_v0.2.md` – WORKING DESIGN / REVIEW: kompakte Hauptmenüs, kontextabhängige zweite Werkzeugzeile, hierarchischer Objektbaum bis zu bearbeitbaren Unterelementen sowie dynamischer Inspector mit Auswahl- und Werkzeugkontext.

## Regel

V0.1 wird nicht still überschrieben. Neue UI-/UX-Entscheidungen werden versioniert dokumentiert und anschließend in eigenen kontrollierten Implementierungsblöcken umgesetzt und getestet.
